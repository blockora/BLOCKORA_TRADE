# core/session.py and pipeline/data_sources.py call ZoneInfo("Asia/Kolkata") at

# --- Optional runtime -------------------------------------------------------
# psutil — NOT a dependency, on purpose.
#   psutil upstream refuses to install on Android ("platform android is not
#   supported"), so a mandatory psutil made `pip install -r requirements.txt`
#   fail outright on Termux.
#   core/system_health.py no longer needs it: system health is read from
#   /proc/meminfo, /proc/stat, /proc/uptime, os.statvfs and os.getloadavg,
#   all of which work on Android. It is used opportunistically when present
#   (desktop gets a first-call CPU% and a couple of extra fields), and the
#   module imports and runs identically without it.
#   Desktop users who want the extra fields can install it themselves:
#       pip install psutil        # desktop / Linux only, never Android


# --- Deliberately NOT dependencies -----------------------------------------
# pandas  — used only by engines/ranking/greeks.py::add_greeks_to_df(), which is
#           never called by the live cycle (its import is lazy). Not declared, so
#           Termux installs do not pull a large binary that has no wheel for the
#           running Python. Install it yourself only if you use that helper.
# numpy   — transitive: needed only alongside pandas. Not declared.
# scipy   — not imported anywhere in this codebase. Not declared.
# nsepython — not imported anywhere and not declared. If you install it manually
#           pip will report that it requires scipy; that is nsepython's own
#           dependency and it is not on the live path. Do not add either to
#           silence that warning.
#
# Removed: ta (technical-analysis). It was never imported by any module in this
# repository and it transitively forced numpy + pandas onto every Termux
# install. Removed rather than version-pinned because no code depends on it.
